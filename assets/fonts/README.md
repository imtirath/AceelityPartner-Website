Place licensed Inter font files here before publishing.

Recommended files (example names used in CSS):
- Inter-Variable.woff2
- Inter-Display.woff2

Instructions:
1. Obtain the Inter variable fonts under the SIL Open Font License (SIL OFL).
2. Put the woff2 files into this folder.
3. The build will copy this folder to dist/assets/fonts and the site will preload them.

Do NOT commit proprietary font files to public repositories without confirming license and project policy.
